### Claude Code Releases

**[v2.1.228](https://github.com/anthropics/claude-code/releases/tag/v2.1.228)**

Eines der umfangreichsten Bugfix-Releases der letzten Zeit. Im Detail:

- **TUI-Redraw-Fix** — Interaktive Sessions konnten nach seltenen Layout-Fehlern komplett einfrieren, während der Prozess weiterlief. Behoben.
- **Windows Git-Bash-Fix** — `git` / Git Bash wurde unter Windows nicht gefunden, wenn Claude Code aus einem übergeordneten Ordner des Git-Installationsverzeichnisses gestartet wurde.
- **`/tui` Modell-Revert-Fix** — `/tui` hat nach einem `/model`-Wechsel das Modell auf den Stand vor der letzten Antwort zurückgesetzt. Behoben.
- **Cross-Session Messaging-Fix** — Nachrichten starteten ohne Inbox, wenn es die erste Session nach Installation oder Upgrade war.
- **Remote Control `/resume`-Fix** — Beim Resuming einer Session über Remote Control wurden Titel und History der resumed Session fälschlicherweise in die verbundene Session durchgereicht.
- **Self-Hosted Runner Checkout-Fix** — Sessions auf frischen Runnern schlugen fehl, wenn der `checkout`-Hook für ein Repository scheiterte, in das die Session nicht pusht. Jetzt wird dieses Repository mit einer Warnung übersprungen.
- **Session Cleanup-Fix** — Beim Aufräumen wurden fälschlicherweise Inhalte im Memory-Ordner eines Projekts gelöscht. Kritischer Fix für Nutzer mit persistentem Memory.
- **Plugin-Cache-Fix** — Hintergrundbereinigung löschte den Cache eines Plugins, wenn dessen einzige Version ein Symlink auf ein Entwicklungs-Checkout war.
- **Settings-Merge-Fix** — Ein Marketplace-Eintrag, der in einer höher priorisierten Settings-Ebene neu definiert wurde, konnte fälschlicherweise Custom Headers einer anderen Ebene erben.
- **Deferred-Tools-Reminder-Fix** — Die Erinnerung wurde gelegentlich nach Skill-Aufruf doppelt an das Modell gesendet.
- **Skills-Sicherheitshärtung** — Von claude.ai synchronisierte Skills können keine lokalen Kommandos oder MCP-Prompts mehr überschatten. Beschreibungen werden sanitiert und gelabelt; `!`-Kommandos und `@`-Dateiexpansionen werden blockiert.
- **Cross-Session Messages verbessert** — Absender und Nachrichtentext erscheinen jetzt inline statt als eingeklappte Zeile.
- **Vertex AI Credential Handling** — Abgelaufene oder fehlende Google Cloud Credentials schlagen jetzt innerhalb von Sekunden fehl statt minutenlang zu retrien.
- **Compaction Progress** — Countdown und Stall-Hinweis erscheinen jetzt während der Compaction.
- **Write Tool-Änderung** — Neuere Modelle können bestehende Dateien überschreiben, ohne sie vorher gelesen zu haben (entspricht nun den Regeln des Edit-Tools). Ältere Modelle müssen Dateien weiterhin erst lesen.
- **Entfernt** — Veralteter Hinweis über leicht höhere Kosten des Auto-Modus aus dem First-Use-Hinweis für Pro-, Max- und Team-Pläne.
