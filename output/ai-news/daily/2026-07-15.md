### Anthropic & Claude

#### [Claude Code v2.1.210](https://github.com/anthropics/claude-code/releases/tag/v2.1.210)

**Neue Features:**
- **Live-Timer in Tool-Zusammenfassung:** Lange laufende Tool-Calls zeigen jetzt einen sichtbar tickenden Zeitstempel, statt eingefroren auszusehen.
- **Startup-Warnung für falsche Permission-Regeln:** `Write(path)`, `NotebookEdit(path)` und `Glob(path)` in Permission-Regeln lösen nun eine Warnung aus — korrekt sind `Edit(path)` bzw. `Read(path)`.
- **Auto-Mode-Verbesserung:** Der Permission-Classifier verwendet jetzt standardmäßig Sonnet 5 für externe Sessions; wird beim ersten Request der Session validiert und für die gesamte Session gepinnt.
- **Verbesserte Bash/PowerShell-Meldung bei Timeout:** Das Modell kann jetzt zwischen einem echten Hang und einem expliziten Hintergrundprozess unterscheiden.
- **Verbessertes Dataviz-Skill:** Chartfarb-Validierung nutzt nun perzeptuellen OKLab-Farbabstand mit neu kalibrierten Farbenblindheits-Schwellenwerten.
- **MEMORY.md Limit-Fehler:** Schreibvorgänge, die den Read-Limit des MEMORY.md-Index überschreiten, erzeugen jetzt einen expliziten Fehler statt stiller Kürzung.
- **Screen-Reader-Modus:** Kündigt Permissionsmoduswechsel beim Shift+Tab-Cycling laut an.
- **Agents-Footer-Hinweis:** Zeigt jetzt, wie viele Hintergrundagenten auf Input warten, mit kurzer Farbbetonung bei Änderungen.
- **Fable temporär nicht verfügbar** im Advisor-Picker aufgrund eines serverseitigen Problems.

**Bugfixes:**
- **`isolation: 'worktree'` Subagenten** konnten git-mutierende Befehle gegen den Haupt-Checkout ausführen statt nur ihren eigenen Worktree — behoben.
- **`ultracode`-Keyword** feuerte fälschlicherweise auf nicht-menschliche Eingaben (Webhook-Payloads, weitergeleitete PR-Kommentare) — behoben.
- **Paste-Marker** (È/É-Zeichen) leckten in externe Editoren, die aus Claude Code geöffnet wurden — behoben.

- **Session-Crash** bei numerischen `bigint`-Werten oder Plaintext aus Tool-Result-Renderern — behoben.
- **Hook-Callback-Timeout** wurde dem Modell fälschlicherweise als User-Ablehnung gemeldet, was unbeaufsichtigte Sessions zum Warten zwang — behoben.
- **`cd`-Befehl im Hintergrund:** Claude nahm fälschlicherweise an, dass `cd` wirksam wurde, wenn der Befehl in den Hintergrund verschoben wurde — Tool-Result meldet jetzt explizit das unveränderte Arbeitsverzeichnis.

- **Plugin-Cache-Schreibvorgänge** hinterließen Temp-Files bei Fehlern und scheiterten bei gesperrten Dateien auf Windows/Netzwerk-Dateisystemen — behoben.

### 📄 ArXiv Papers

- **[Do AI Agents Know When a Task Is Simple?](http://arxiv.org/abs/2607.13034v1)** — LLM-Agenten unterschätzen systematisch die Einfachheit von Aufgaben und verfolgen eine „Maximum-Context-First"-Strategie: Statt direkter Ausführung lesen sie bereits bekannte Dateien erneut. Die Arbeit argumentiert für *task-aware execution-scope estimation* als fehlende Kernfähigkeit.

- **[TerraZero: Procedural Driving Simulation for Zero-Demonstration Self-Play](http://arxiv.org/abs/2607.13028v1)** — Prozeduraler Fahrsimulator für autonomes Fahren, der 1,3 Millionen Agent-Steps/Sekunde über Zero-Copy CPU/GPU-Pfad erreicht. Ermöglicht RL-Training ohne Demonstrations-Daten und deckt Safety-kritische Randfälle ab, die Logged-Data kaum enthält.

- **[PalmClaw: A Native On-Device Agent Framework for Mobile Phones](http://arxiv.org/abs/2607.13027v1)** — Framework für native LLM-Agenten direkt auf Smartphones, ohne Umweg über grafische Benutzeroberflächen. Mobile Geräte werden als vollwertige Agenten-Umgebung mit Zugang zu Nutzerdaten, Sensoren und Apps behandelt.

- **[Audio-Native Speech Recognition with a Frozen Discrete-Diffusion LM](http://arxiv.org/abs/2607.13013v1)** — DiffusionGemma (26B MoE) transkribiert Sprache nicht autoregessiv Token-für-Token, sondern verfeinert den gesamten Transcript parallel über wenige Diffusionsschritte. Zeigt, dass diskrete Diffusionsmodelle als ASR-Backend konkurrenzfähig sein können.

- **[The Illusion of Robustness](http://arxiv.org/abs/2607.12963v1)** — State-of-the-art LLMs wirken auf Aggregat-Ebene robust gegenüber aufgaben-irrelevantem Kontext, zeigen aber auf Einzelbeispiel-Ebene signifikante Vorhersage-Flips. Semantisch bedeutungslose Kontextänderungen können Modell-Antworten kippen, ohne die Gesamt-Accuracy zu verändern.

- **[MemOps: Benchmarking Lifecycle Memory Operations](http://arxiv.org/abs/2607.12893v1)** — Neues Benchmark für Langzeit-Gedächtnis-Operationen von LLM-Agenten über mehrere Sessions hinweg — bewertet nicht nur die finale Antwort, sondern einzelne Memory-Operationen (Einführen, Binden, Updaten, Abrufen, Löschen) in ihrem Lebenszyklus.

- **[LLM Judges Can Be Too Generous Without a Reference Answer](http://arxiv.org/abs/2607.12885v1)** — LLM-als-Judge-Systeme neigen in No-Reference-Settings dazu, Antworten zu milde zu bewerten. Die Studie zeigt, dass das Kalibrierungswissen des Judges über die beurteilte Aufgabe sowie Position und Vorhandensein von Referenzantworten die Bewertungsqualität erheblich beeinflussen.
