### Claude Code Releases

**[v2.1.223](https://github.com/anthropics/claude-code/releases/tag/v2.1.223)**

Dieses Release ist eines der umfangreichsten der letzten Zeit mit mehreren kritischen Sicherheitsfixes und bedeutenden neuen Features:

**Neue Features:**
- **Owner-Wildcard-Einträge** (`"owner/*"`) für `strictKnownMarketplaces` und `blockedMarketplaces` — ermöglicht das pauschale Erlauben oder Blockieren aller Marketplace-Repos unter einer GitHub-Org
- **Warnhinweis bei eingeschränktem Subagent-Modell** — wenn ein Workflow-Agent, ein geforkter Skill, ein Slash-Command oder ein wiederaufgenommener Hintergrund-Agent ein Modell anfordert, das gesperrt ist und stattdessen das Eltern-Modell läuft, erscheint jetzt eine Warnung
- **`/teleport`-Hinweis in Cloud-Sessions** — zeigt, wie man eine Cloud-Session lokal mit `claude --teleport <session id>` fortsetzt
- **`/review` ist jetzt Alias für `/code-review`** — unified-Command, der das aktuelle Diff oder einen PR reviewt (`/code-review <level> <pr#>`); `/code-review ultra` für tiefen Cloud-Review
- **`/code-review` merkt sich den letzten Effort-Level** — kein erneutes Tippen nötig, bis man ihn ändert
- **`CLAUDE_CODE_DISABLE_1M_CONTEXT`** hält jetzt jedes Claude-Modell mit nativem 1M-Fenster auf 200K per Auto-Compaction (nicht mehr nur eine feste Liste); Startup-Warnung wenn Auto-Compaction nicht greift
- **Auto-Compact** hält Sessions bei unbekannten Modell-IDs im angenommenen Kontextfenster (statt wachsen zu lassen); deaktivierbar mit `CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT=1`

**Sicherheitsfixes (kritisch):**
- **Bash-Permission-Bypass behoben** — ein manipuliertes Kommando konnte Teile von sich vor den Permission-Checks verstecken
- **Tab- und Unicode-Padding in Kommandos** — Befehle, die mit Tabs oder unsichtbaren Unicode-Zeichen aufgefüllt wurden, konnten Teile vor dem Genehmigungsdialog verbergen → behoben
- **Workflow-Sandbox-Escape via `import()`** — Workflow-Skripte konnten dynamisches `import()` nutzen, um Code außerhalb der Sandbox auszuführen → behoben
- **`bypassPermissions`-Policy-Gap** — eine Agent-Definition konnte `bypassPermissions` ignorieren, wenn die Org-Policy das Bypass deaktiviert hatte → behoben
- **Sandbox-Start auf Linux** — sandboxed Commands starteten nicht, wenn `sandbox.filesystem.denyWrite` das Arbeitsverzeichnis abdeckte → behoben

**Weitere Fixes:**
- Session-Wiederaufnahme nach `/cd` im laufenden Betrieb lieferte leeren Zustand → behoben
- Gateway-Modell-Discovery versteckte Claude-Modelle unter Provider-Präfix-IDs wie `vertex_ai/claude-*` oder `bedrock/anthropic.claude-*` → behoben
- `modelOverrides`-Keys, die keine Anthropic-Modell-IDs sind, wurden fälschlich als kanonische Modell-ID behandelt → unbekannte Keys werden jetzt ignoriert
- Managed Settings: Server-gelieferte Settings deaktivierten fälschlich den `env`-Block in lokalen `managed-settings.json`; Admin-Env mergt jetzt key-weise
- Hintergrund-Agents blieben bei fehlgeschlagenem Fork-Resume-Rebuild in „already resuming" hängen → behoben
- Wiederaufgenommene Sessions mit malformed Diagnostics-Attachment führten zu Fehler-Loop → behoben
- Seltener Hang beim Parsen ungewöhnlicher `git push`-Ausgabe → behoben

### Claude Agent SDK (TypeScript)

**[v0.3.223](https://github.com/anthropics/claude-agent-sdk-typescript/releases/tag/v0.3.223)**

**Neue Features:**
- **`resumeDropsTurn`-Option** — zusammen mit `resumeSessionAt` deklariert diese Option den Turn, den ein truncating Resume verwerfen will; die CLI verweigert den Resume, wenn etwas anderes verworfen würde
- **529-Overload-Erkennung** — Result-Messages bei wiederholten 529-Fehlern enthalten jetzt `api_error_status: 529`, damit SDK-Consumer Overload-Abbrüche strukturell erkennen können (ohne Text-Matching)
- **`system/permission_denied`-Stream-Events** — Bare Headless (`-p` / `query()` ohne `canUseTool`) emittiert jetzt diese Events, wenn ein Tool-Call automatisch abgelehnt wird
- **Klarere Dokumentation `usage` vs. `modelUsage`** auf Stream-JSON-Ergebnissen: `usage` ist nur Main-Loop und per-Turn; `modelUsage` ist kumulativ, deckt alle Query-Pipeline-Calls ab und ist das Feld für Cost-Accounting

**Update:**
```sh
npm install @anthropic-ai/claude-agent-sdk@0.3.223
```

#### Meta (TechCrunch / VentureBeat)

**[Meta launcht Muse Code + Muse Spark 1.2](https://techcrunch.com/2026/08/05/meta-launches-muse-code-an-ai-agent-for-large-code-bases/)**

Meta betritt den Coding-Agent-Markt mit einer Doppelstrategie:

**Muse Code (Terminal-Agent, Beta):**
- Installierbar per `curl -fsSL https://dev.meta.ai/install.sh | bash`
- **Persistente Hintergrund-Agents** — bleiben für die gesamte Session aktiv statt für jede Aufgabe neu gestartet zu werden; vermeidet redundantes Repository-Erkunden

**Muse Spark 1.2:**
- Coding-fokussiertes Update von 1.1 mit signifikant mehr Training-Compute
- Co-trainiert mit Muse Code selbst (harness trajectories)
- Benchmarks: Terminal-Bench 2.1: 82.9% (hinter Opus 5 mit 86.7%), DeepSWE 1.1: 59.3% (hinter Opus 5 mit 65.0%)
- Auf Metas eigenem internen Benchmark: 70.6% vs. Opus 5's 79.4% — Meta gesteht offen, dass Anthropic gewinnt

**Preismodell:**
| Tier | Input | Output |
|------|-------|--------|
| Standard (kein Training) | $1.25/M | $4.25/M |
| Contributor (Training erlaubt) | $0.10/M | $0.20/M |

### 📄 ArXiv Papers

**[Argus: A General-Purpose Agentic Runtime for Long-Horizon Reasoning](http://arxiv.org/abs/2608.05144v1)**
Präsentiert Argus, ein persistentes, selbst-evolvierendes Runtime-System mit Manager, Planner, Engineer und Reviewer-Rollen über dauerhaftem Projektzustand. Trennt stabile Nutzerintention von operativen Zielen und Verifikationskriterien — ausgelegt für lange Horizonte mit Selbstkorrektur.

**[OctoLong: Mid-Training auf Cross-Repository Code Contexts](http://arxiv.org/abs/2608.05141v1)**
Einführung einer Context-Engineering-Pipeline, die AST-Parser, Language-Server-Backend und Package Manager nutzt, um synthetische Cross-Repository-Trainingsdaten zu erstellen. Adressiert den Mangel an langen Code-Kontexten mit echten Long-Distance-Dependencies in bestehenden Corpora.

**[Reasoning Core: Procedural Data für Completion-Supervised Reasoning Training](http://arxiv.org/abs/2608.05148v1)**
50 Generatoren über Mathematik, Logik, Planung, formale Sprachen, Games und Code — mit Schwierigkeitskontrolle und semantischen Scorern. Vergleich mit Procedural Warmup und ReasonFlux unter matched Completion-Supervised-Protokoll.

**[Toward Skill-Native LLMs: Skill Entropy für Cross-Skill Long-Horizon Tasks](http://arxiv.org/abs/2608.05139v1)**
Neue Metrik „Skill Entropy" zur Messung von Skill-Wechseln in Reasoning-Chains. Adressiert die Lücke, dass aktuelle Benchmarks einzelne Skills testen, aber nicht wie gut Modelle zwischen Skills wechseln — z.B. Mathe → Terminplanung innerhalb einer Kette.

**[OPD-V: Visual On-Policy Self-Distillation mit Modality Balance](http://arxiv.org/abs/2608.05131v1)**
Adressiert Modality Imbalance in MLLMs: wenn Text die Generierung dominiert, kann das Modell seinen multimodalen Input nicht vollständig integrieren. Neuer Self-Distillation-Ansatz mit explizitem Modality-Balancing.

**[Chained Recursive Language Models für Multi-Iteration Reasoning](http://arxiv.org/abs/2608.05124v1)**
Chained RLM: Inference-Architektur für Long-Context-Aufgaben (Extraktion, Counting, Multi-Hop), die frühe Fehler durch rekursive Ketten verhindert statt eine einzelne lange Inference-Trajektorie zu nutzen.

**[Spoken Function Calling (SFC)](http://arxiv.org/abs/2608.05126v1)**
Neuer Ansatz für Spoken Language Understanding: statt traditionellem geschlossenen SLU werden Tool-Call-Paradigmen aus LLMs auf Audio-Modelle übertragen, um offene Domains per In-Context-Learning zu erschließen.

**[SSTQ: Privacy-Preserving Vector Quantization](http://arxiv.org/abs/2608.05127v1)**
Subsampled Stochastic TurboQuant kombiniert overcomplete equal-norm tight frames, Koordinaten-Subsampling und datenschutzgerechte 1D-Quantisierung für lokale Differential Privacy in verteilter Optimierung — verbessert dimensionsabhängige Varianz gegenüber vqSGD.

**[Teaching Nemotron Greek: RAG für Griechisch](http://arxiv.org/abs/2608.05138v1)**
End-to-End-Adaptation von NVIDIAs Nemotron Retrieval-Stack für Neugriechisch: Corpus Mining, synthetische Supervision, Retrieval-Training, Reranker, Reader-Fine-Tuning und neuer HERA-Benchmark — für Legal, Energy, Finance und Medical.
