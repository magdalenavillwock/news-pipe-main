### Claude Code Releases

**[v2.1.237](https://github.com/anthropics/claude-code/releases/tag/v2.1.237)**
- **Bugfix:** Prompt Caching repariert für Sessions, die über ein LLM-Gateway oder eine Custom Base URL laufen — wichtig für alle, die Claude hinter einem Proxy oder Third-Party-Gateway nutzen.
- **Neues Feature: „Concise" Output Style** — Claude kommt direkt zum Ergebnis, überspringt Präambel und Narration, arbeitet aber genauso gründlich. Auswählbar unter `Output style` in `/config`.

**[v2.1.236](https://github.com/anthropics/claude-code/releases/tag/v2.1.236)**
Eines der umfangreichsten Releases seit Langem mit über 25 Änderungen:

*Neue Features:*
- **`ANTHROPIC_DEFAULT_MODEL` Env-Variable:** Setzt das Startmodell neuer Sessions; ein `/model`-Pick überschreibt es und bleibt über Neustarts hinweg persistent (anders als `ANTHROPIC_MODEL`).
- **`notify_when_idle` für Cross-Session `SendMessage`:** Eine andere Claude Code Session auf demselben Rechner kann benachrichtigt werden, wenn sie das nächste Mal idle geht — opt-in, einmalig, kein Polling (macOS und Linux).
- **Sandbox (macOS):** Wildcard-Read-Deny-Rules (z.B. `**/.env`) haben nun Vorrang innerhalb erlaubter Lesebereiche, erfassen Verzeichnisinhalte und können nicht durch Umbenennen der blockierten Datei umgangen werden.
- **Auto-Modus:** `Monitor`-Allow-Rules werden während des Auto-Modus beiseitegestellt, damit Monitor-Befehle genauso wie Bash-Befehle geprüft werden.
- **Auto-Modus verbessert auf Bedrock, Vertex AI und Foundry** sowie bei deaktivierter Telemetrie: Classifier nutzt nun dieselben Defaults wie auf der Claude API, inkl. Severity-Scoring.
- **Auto-Modus:** Git-Status-Check kann nicht mehr durch `status.showUntrackedFiles=no` getäuscht werden.
- **`/goal`:** Eine idle Session, deren Ziel hinter laufenden Background-Tasks steckt, checkt nun automatisch nach 30 Minuten (dann 1h, 2h) ein.
- **`/usage`:** Zeigt jetzt die Usage-Credits-Ausgabe für Team- und Enterprise-Mitglieder.
- **Remote Control:** Markiert eine Session innerhalb von Sekunden als offline, wenn die CLI beendet oder das Terminal geschlossen wird.
- **VSCode:** Screen-Reader-Support für das Transcript hinzugefügt (Live-Announcements für Antworten, Berechtigungsanfragen, Fehler, Statusänderungen).
- **`/model`-Picker:** Zeigt jetzt nur so viele Modelle, wie ins Fenster passen; Rest per Scrollen erreichbar.
- **Footer:** Rechts ausgerichtete Elemente (Goal-Indikator, Session-State, Background-Agent-Status) mit einheitlichem rechten Rand.

*Bugfixes (Auswahl):*
- Clipboard-Copy, Background-Housekeeping, Background-Sessions und lokale MCP-Logs kaputt nach Löschen des Session-Verzeichnisses (seit 2.1.229) — **behoben**.
- Fullscreen-Renderer fiel nach einem fehlgeschlagenen Start permanent aus — fällt nun auf den Classic Renderer zurück.
- `SendMessage` lehnte Nachrichten ab, wenn ein fehlerhafter Closing-Tag den Nachrichtentext in das Summary-Feld verschob.
- Unhandled Promise Rejections beim Fehlstart eines Subprozesses (z.B. `powershell.exe` auf WSL mit deaktiviertem Windows Interop) — Regression aus 2.1.234.
- Fullscreen: Leerzeile über dem Prompt nach Löschen einer mehrzeiligen Eingabe; Panes wurden nach Terminal-Resize nicht neu gezeichnet.
- Terminal-Tab-Titel sprangen in tmux (iTerm tmux integration) alle 960ms — wird jetzt nur bei Textänderung geschrieben.
- Fable 5 Erstnuztungs-Prompt wählte nach 60 Sekunden automatisch das Fallback-Modell, wenn Remote Control aktiv war.
- Spinner-Tips erschienen nie (seit Fehler im gecachten `~/.claude.json`).
- Skills Hot-Reload in SDK/VS Code schlug nach Löschen des Working Directory fehl (2.1.229+).
- Self-hosted Runner: Sessions, die bei Idle/Retire/Startup-Timeout freigegeben wurden, wurden gelegentlich auf einem anderen Runner fortgesetzt, bevor der Post-Session-Hook beendet war.
- Session-Recaps unbegrenzt lang — jetzt auf 400 Zeichen begrenzt (Wortgrenze).
- Managed-Settings-Approval-Prompt erschien manchmal nicht beim Start, obwohl der erste Tastendruck als Zustimmung gezählt wurde.

*Verbesserungen:*
- Startup-Performance: Session-Counter wird im Hintergrund geschrieben.
- `SendMessage` lehnt weitere Nachrichten frühzeitig ab, wenn ein schneller Burst das Inbox-Limit der Zielsession überschreiten würde.
- SIGTERM im Print/SDK-Modus erzeugt keine unterbrochenen Turns oder synthetischen Tool-Denials mehr; laufende Befehle werden terminiert, Prozess beendet mit Code 143.
- Enter auf einem Slash-Command-Tippfehler oder nicht verfügbarem Befehl meldet den Fehler statt den nächsten Fuzzy-Match auszuführen.

**[Asynchrone Patterns für AgentCore Agents in Serverless Pipelines](https://aws.amazon.com/blogs/machine-learning/asynchronous-patterns-for-calling-amazon-bedrock-agentcore-agents-in-serverless-pipelines/)**
Drei Patterns zur kostengünstigen Einbindung von AgentCore-Agents in Step Functions:
1. **Task-Token Callback:** Lambda gibt sofort zurück, Step Functions wartet auf Agent-Callback.
2. **Direct Service Integration:** Kein Lambda mehr — Step Functions ruft AgentCore direkt auf.
3. **Lambda Durable Function:** Orchestrierung als Code mit `waitForCallback`, kein idle Compute.
Konkretes Messbeispiel: State war 19,6s aktiv, Lambda-Dispatcher aber nur 4,8s in Rechnung gestellt.

### 📄 ArXiv Papers

**[SPADE: Self-Play in Adaptive Synthetic Executable Environments](http://arxiv.org/abs/2608.19197v1)**
Ein Self-Play-RL-Framework, bei dem ein einzelnes LLM zwei Rollen spielt: Environment Designer (schreibt vollständige, langfristige Trainingsumgebungen) und Agent (löst diese). Adressiert das Problem, dass bestehende Trainingsumgebungen die Zielverteilung beim Skalieren fixiert halten. Kontinuierliche Selbstverbesserung durch sich erweiternde, diversifizierte, adaptive Ziele.

**[ADEPT: Accelerating Dexterity via Pre-Training and Post-Training using RL](http://arxiv.org/abs/2608.19182v1)**
Großskaliges RL-Framework für Sim-to-Real-Transfer-fähige Roboter-Dexterity bei hochfreiheitlichen Embodiments (HDoF). Vortraining auf einem generischen Objekt-Repositionierungstask, dann Post-Training auf Downstream-Tasks mit dem vortrainierten Verhalten als Prior. Rohe visuo-taktile Wahrnehmung, direkte Lösung von Long-Horizon-Tasks.

**[Group-Calibrated On-Policy Distillation](http://arxiv.org/abs/2608.19181v1)**
Diagnostiziert einen Mismatch bei On-Policy-Distillation (OPD) in Long-Context-Tasks: Token-Level-Teacher-Guidance begünstigt lokal plausible Antworten, die global verteilte Evidenz übersehen. Schlägt group-kalibrierte Alternativen vor, die Task-spezifische Verifier mit abgestuften Belohnungen kombinieren.

**[Open-MOPD: Multi-Teacher On-Policy Distillation](http://arxiv.org/abs/2608.19098v1)**
Kontrollierter Benchmark auf SmolLM3-3B für Multi-Teacher OPD — konsolidiert domain-spezialisierte RL-Experten in einem generalistischen Schülermodell via dense token-level reward supervision. Erste rigorose, reproduzierbare Recipes für dieses Paradigma.

**[Interpretable AI predicts 2026 summer dry anomaly in central China](http://arxiv.org/abs/2608.19163v1)**
Deep-Learning-Modell übersetzt dynamische Zirkulationsvorhersagen in Niederschlagsschätzungen. Seit März konsistente Vorhersage einer Trockenanomalie über Zentralchina im Sommer 2026 — höhere Vorhersagegüte in analogen Jahren.

**[ChildSafeAds Shared Task 2026](http://arxiv.org/abs/2608.19165v1)**
Shared Task zur Erkennung kommerzieller Inhalte in YouTube-Videos, die wahrscheinlich Kinder und Jugendliche erreichen. 3.360 Videos aus 939 Kanälen, gepaart mit SponsorBlock-Segmenten, Transkripten und verlinkten Produktseiten.
