### Claude Code Releases

**[v2.1.280](https://github.com/anthropics/claude-code/releases/tag/v2.1.280)**

Eines der bislang umfangreichsten Claude Code Releases. Highlights:

**Neue Features:**
- **Claude Opus 5.5** (`claude-opus-5-5`) ist jetzt das Standard-Opus-Modell — 1M Kontext, $4/$20 pro MTok, Cache-Reads $0.20/MTok

- Prompt-Zeile blieb nach unsichtbaren Zeichen auf Windows-Terminals verzerrt — Screen wird jetzt neu gemalt

- Voice-Diktat stoppte nicht auf Ctrl+C, Esc cancelte nicht während Transkription lief — gefixt

- Resumierte Fork-Subagenten rebuildierten Tool-Liste statt die originale zu senden — Cache-Busting gefixt
- `installed_plugins.json` behielt nach Branch-Update alten Commit — gefixt
- Skills in `~/.claude/skills/` wurden fälschlicherweise in Trash verschoben — gefixt
- Sessions schlugen mit "role 'system' must precede 'assistant'" API-Fehler fehl — gefixt
- Advisor-Konversationen schlugen mit API 400 hinter Proxies fehl — Retry ohne Advisor-Tag
- Crash beim Resumieren von Sessions mit malformen System-Messages — gefixt
- Claude Code hing, wenn Settings-Datei durch Named Pipe mid-read ersetzt wurde
- `/config` crashte bei veralteten `null`/`"false"` Werten in `~/.claude.json`
- Hintergrund-Subagenten konnten LSP-Tool nicht nutzen — gefixt

## 📄 ArXiv Papers

**[CliffCompaction: Kosteneffiziente Kompaktierung für Coding-Agenten](http://arxiv.org/abs/2609.26779v1)**
Neue Autocompaction-Technik, die Kosten um bis zu 50% bei beschränktem Kontext reduziert — bei gleicher oder verbesserter Performance auf Terminal-Bench und KernelBench. Hochrelevant für Langzeit-Agentic-Workflows wie Claude Code.

**[A2M: MCP-Agenten-Hijacking durch optimierte Metadaten](http://arxiv.org/abs/2609.26761v1)**
Two-Stage-Framework für Black-Box-Angriffe auf MCP-Agenten: Attraction-Phase optimiert Tool-Metadaten für höhere Invokationswahrscheinlichkeit; Manipulation-Phase nutzt Ausführungs-Traces für adversarielle Tool-Outputs. **Sicherheitsrelevant für alle MCP-Deployments.**

**[SWE-Serve: Benchmark für Production-Inference-Engineering](http://arxiv.org/abs/2609.26777v1)**
