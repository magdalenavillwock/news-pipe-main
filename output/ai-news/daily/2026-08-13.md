#### [Claude Code v2.1.229](https://github.com/anthropics/claude-code/releases/tag/v2.1.229)

Eines der umfangreichsten Claude Code Releases. Alle Änderungen im Detail:

**Neue Features:**
- **`claude remote-control --continue`** — Dokumentiert für das Fortsetzen der zuletzt verwendeten Remote-Control-Session
- **Server-supplied Hooks für Self-Hosted Runner** — Claude Code Hooks werden jetzt auch in self-hosted Runner-Sessions unterstützt (Parität mit managed Environments)
- **SSE Keepalive-Pings** — Gateway-Streaming-Antworten senden jetzt Keepalive-Pings während langer Thinking-Pausen, verhindert Idle-Timeout-Disconnects auf Vertex und Bedrock
- **Plugin-Marketplace `command`-Quellen** — Ein lokaler Befehl (z.B. aus einer IDE) gibt das Plugin-Verzeichnis aus; `mode: "link"` nutzt es direkt; wird pro Session neu aufgelöst und ohne Neustart angewendet
- **`ListAgents` Verbesserungen** — Getrennte Remote-Control-Sessions werden als `offline` markiert; Cloud-Sessions werden als `cloud` gekennzeichnet
- **Workflow-Fan-out-Optimierung** — Geschwister-Agents mit gleichem Prefix werden gestaffelt gestartet, sodass folgende Agents den gecachten Prompt-Prefix nutzen (deaktivierbar via `CLAUDE_CODE_WORKFLOW_PREFIX_STAGGER_MS=0`)
- **IPv6-Literals in Sandbox-Netzwerklisten** werden jetzt korrekt geklammert (`[::1]:443`); ambige Schreibweisen werden fail-closed durchgesetzt und von `/doctor` gemeldet
- **[VSCode] Session-Gruppen** — Rechtsklick zum Erstellen, Umbenennen oder Löschen; Cmd/Ctrl- oder Shift-Klick zum Verschieben mehrerer Sessions
- **[VSCode] `/btw`-Panel** — Das Seitenbereich-Panel für Rückfragen ist jetzt durch Ziehen der Grenze in beiden Layouts (side-docked und gestapelt) in der Größe veränderbar

**Fixes:**
- Lange Antworten verschwanden teilweise beim Streaming und wurden doppelt im Terminal ausgegeben — **behoben**
- Crash beim Error-Screen (auch bei `--resume`) wenn ein Tool-Call einen non-string `glob`, `file_path` oder `command`-Wert hatte — **behoben**
- `RangeError`-Crash bei sehr schmalen Terminals (Progressbar oder Markdown-Tabelle) — auch bei `--continue`/`--resume` beim Start — **behoben**
- Crash auf Windows bei Extended-Length-Pfaden (`\\?\`) oder UNC-Pfaden — **behoben**
- Auto-Mode schlug bei jedem Tool-Call fehl für Nutzer, die den Attribution-Header via `CLAUDE_CODE_ATTRIBUTION_HEADER` deaktiviert haben (direkte Anthropic API) — **behoben**
- `/model` lehnte Sonnet/Opus 1M für claude.ai-Subscriber mit eigenem `ANTHROPIC_BASE_URL`-Gateway ab — **behoben**
- MCP OAuth mit strikten Autorisierungsservern: `127.0.0.1` statt `localhost` im Redirect-URI — **behoben**
- Remote-Control-Clients zeigten einen hängenden Spinner nach Slash-Commands im Laptop-Terminal — **behoben**
- Claude Code Review Workflow (generiert durch `/install-github-app`) schloss ab ohne Review zu posten — **behoben**
- Mehrsekundige UI-Stalls nach Datei-Edits mit tausenden IDE-Diagnostics bei verbundener IDE-Extension — **behoben**
- Einmalige `claude plugin`-Commands hinterließen eine veraltete Liveness-Datei, die Cleanup alter Plugin-Versionen verhinderte — **behoben**
- Dynamische Workflows in CPU-limitierten Containern nutzten die Core-Anzahl des Host-Rechners statt des Container-Limits — **behoben**
- File-Watcher Handle-Leak nach atomaren Datei-Ersetzungen; ungefangener Fehler auf Windows bei scheduled-tasks-Watcher auf Netzwerk- oder virtuellen Dateisystemen — **behoben**
- SDK und `--input-format stream-json`-Sessions erhielten 400 API-Error bei whitespace-only Nachrichten — **behoben**
- Conversations, deren Nachrichten allein das 32-MB-Request-Limit überschreiten, versuchten endlos Compaction; jetzt klarer Fehler — **behoben**
- OpenTelemetry-Export von Claude Desktop wurde vom Desktop-managed Gateway abgelehnt — **behoben**
- Self-hosted Runner und Remote-Sessions exiteten beim Start wenn `managed-mcp.json` deployt ist; MCP-Server werden jetzt mit Warnung übersprungen — **behoben**
- Self-hosted Runner hing bei Git Credential Manager-Prompt; git schlägt jetzt schnell fehl wenn Credentials fehlen — **behoben**

**Verhaltensänderungen:**
- **`/commit-push-pr`**: Git/gh-Befehle mit gefährlichen Flags (`--force`, `--amend`, `--no-verify` etc.) werden nicht mehr auto-approved
- **Self-hosted Runner Windows**: Startup erfordert jetzt explizites `--base-dir`; kein Standardverzeichnis mehr auf Windows
- **`/login`**: Wiederholt die `CLAUDE_CODE_OAUTH_TOKEN`-Override-Warnung nach erfolgreichem Login
- **[VSCode] „Report a Problem" und `/bug`**: Öffnen jetzt den eingebauten Feedback-Dialog statt eines eingestellten Survey-Links

### 📄 ArXiv Papers

**[AI4AI at Test-Time: Strong-to-Weak Capability Transfer via Harnesses](http://arxiv.org/abs/2608.12307v1)**
Untersucht, ob ein stärkeres "Builder"-Modell zur Laufzeit Inference-Harnesses konstruieren kann, die ein schwächeres Zielmodell bei der Aufgabenerfüllung zuverlässiger machen — ohne Parameter-Updates. Ein vielversprechender Ansatz für Capability Transfer ohne Distillations-Training.

**[DreamFly: Aerial Vision-Language Navigation](http://arxiv.org/abs/2608.12308v1)**
Diffusion-basiertes Framework für VLN (Vision-Language Navigation) in der Luft: Kombiniert kausales Memory und Receding-Horizon-Planung für robustere Navigation unter partieller Observierbarkeit.

**[Redistribution-based Cost Inference for Safe Offline RL](http://arxiv.org/abs/2608.12306v1)**
**RCI-Framework**: Wandelt sparse Stop-Feedback (binäres Signal bei unsicherem Übergang) in dichte per-Step-Kosten um via Return Decomposition — löst das Temporal Credit Assignment-Problem für Safe Offline RL ohne dichte Annotationen.

**[KG-DML: Knowledge Graphs für Complex System Diagnostics via RAG-LLMs](http://arxiv.org/abs/2608.12304v1)**
Automatische Konstruktion von Dynamic Master Logic Modellen als Knowledge Graphs aus technischer Dokumentation mit Retrieval-Augmented Generation — ersetzt manuelle Expertenkonstruktion.

**[AVA-Encoder: Agent-Native Video Representation](http://arxiv.org/abs/2608.12313v1)**
Agentic Video Auto-Encoder für das Lernen filmischer Video-Repräsentationen, die direkt für agentic Reasoning und Manipulation nutzbar sind.

**[Structural Silence: AI Failures for Underrepresented Languages](http://arxiv.org/abs/2608.12278v1)**
Untersucht, wie AI-Infrastruktur (Training Corpora, Tokenization, Benchmarks) Sprecher von Bengali und anderen weitverbreiteten aber unterrepräsentierten Sprachen systematisch benachteiligt — strukturelle Barrieren, nicht Modellschwächen.

**[CAM Survey: Class Activation Mapping Review](http://arxiv.org/abs/2608.12299v1)**
Umfassende Überblicksarbeit zu CAM-Methoden für Explainable AI in Computer Vision: Von CNN-Klassifikatoren über Transformer bis zu Foundation Model-Ära-Erklärungen.

**[LLM-Driven Small-Cap Trading](http://arxiv.org/abs/2608.12283v1)**
Uncertainty-aware Portfolio-Konstruktion mit LLM-Sentiment-Signalen: Aleatoric und epistemische Unsicherheitskomponenten werden direkt in die Kovarianzmatrix von Portfolio-Allokatoren eingespeist — evaluiert auf Russell 2000.
