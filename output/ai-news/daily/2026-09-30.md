### Claude Code Releases — v2.1.285

**[Release Notes v2.1.285](https://github.com/anthropics/claude-code/releases/tag/v2.1.285)**

Eines der umfangreichsten Releases. Vollständige Auflistung:

**Neue Features:**
- `CLAUDE_CODE_DISABLE_WEB_FETCH` — Umgebungsvariable zum Deaktivieren des WebFetch-Tools
- `claude --desktop` — Öffnet die Claude Desktop App im aktuellen Verzeichnis, mit `--continue`/`--resume <id>` auch in bestehenden Sessions
- `claude plugin configure <plugin>` — Zeigt Plugin-Optionen und ungesetzte Felder; liest neue Werte via `--values-stdin` aus stdin
- `<server>.<key>=<value>` in `claude plugin install --config` — Erlaubt das Setzen von MCP-Server-Einstellungen direkt bei der Installation
- `allowedProviders` Managed Setting — Schränkt erlaubte API-Provider pro Maschine ein (Anthropic, Bedrock, Vertex AI, Foundry, etc.)
- `CLAUDE_CODE_NONSTREAMING_TIMEOUT_RETRIES` — Begrenzt Wiederholungsversuche bei Timeout des Non-Streaming-Fallbacks
- **[VSCode]** Hinweisnotiz unter letzter Nachricht bei unterbrochenen Tabs nach Window-Reload
- **[VSCode]** Plugin-Optionsformular in "Manage plugins" — fragt ungesetzte Optionen ab und ermöglicht spätere Änderung
- **[VSCode]** On-demand Diagnostics Tool — Claude im Panel kann das Problems-Panel jederzeit auslesen

**Bugfixes (Auswahl):**
- `claude -p` mit `CLAUDE_CODE_FORK_SUBAGENT=1`: Subagent-Agent-Calls laufen jetzt korrekt im Vordergrund
- Plugin/Marketplace-Installs via SSH respektierten `GIT_SSH`/`core.sshCommand` nicht

- `claude plugin disable`/`enable` mit vollständiger `name@marketplace`-ID änderte falschen Eintrag

### 📄 ArXiv Papers

**[Skill-Space Shooting for Autonomous Robot Policy Improvement](http://arxiv.org/abs/2609.38178v1)**
Roboter müssen sich über das initiale Training hinaus verbessern können. Dieses Paper nutzt Foundation Models zur autonomen Komposition gelernter Verhaltensweisen — ohne menschliche Demonstration jeder Korrektur.

**[STEPQuant: When and Where Errors Matter in Delta-Rule Recurrent State Quantization](http://arxiv.org/abs/2609.38169v1)**
Lineare Attention mit Fixed-Size Recurrent States als KV-Cache-Ersatz. Problem: Direkte Low-Precision-Quantisierung der Zustände führt zu Qualitätsverlust durch Error-Propagation. STEPQuant identifiziert *wann* und *wo* Fehler besonders schaden (zeitliche Persistenz + räumliche Sensitivität).

**[LeapQuant: Efficient Linear Attention with Accurate Recurrent State Quantization](http://arxiv.org/abs/2609.38166v1)**
Ergänzung zu STEPQuant: LeapQuant löst das Quantisierungsproblem für hybride LLMs (Gated DeltaNet, Kimi Delta Attention) — reduziert Inference-Bottleneck beim Lesen/Schreiben des Recurrent State ohne signifikante Qualitätseinbußen.

**[Beyond the Timeline: Augmenting Long-Video Memory with Grounded Entity Biographies](http://arxiv.org/abs/2609.38155v1)**
Videos über viele Stunden: dasselbe Objekt erscheint in verschiedenen Events, aber chronologische Beschreibungen können physische Identität nicht auflösen. "Grounded Entity Biographies" verknüpfen Beobachtungen desselben Objekts über den gesamten Zeitraum.

**[Thinking Before Thinking: Scaling Agentic Inference Through Meta-Reasoning](http://arxiv.org/abs/2609.38147v1)**
