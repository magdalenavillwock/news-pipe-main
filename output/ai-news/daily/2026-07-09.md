### Claude Code Releases — v2.1.205

**Sicherheit & Auto-Mode:**
- Neue Auto-Mode-Regel blockiert Manipulationen an Session-Transcript-Dateien
- Auto-Mode fragt jetzt nach Bestätigung vor `rm -rf` auf Variablen, die aus dem Kontext nicht auflösbar sind
- Background-Task-Benachrichtigungen dokumentieren explizit, dass kein menschlicher Input stattgefunden hat — verhindert fabrizierte Genehmigungen in Transcripts

**Bugfixes — JSON & Schema:**
- `--json-schema` produzierte bei ungültigem Schema stillschweigend unstrukturierte Ausgaben — behoben
- Schemata mit `format`-Keyword wurden fälschlicherweise abgelehnt — behoben

**Bugfixes — Messaging & Turns:**
- Nachrichten, die während einer laufenden Antwort gesendet wurden und beim `--max-turns`-Limit verloren gingen — behoben
- Background-Jobs wechselten fälschlicherweise von „needs input" zu „working" bei Turns ohne lesbaren Text — behoben

**Bugfixes — Windows:**
- Worktree-Removal löschte Dateien außerhalb des Worktrees bei NTFS-Junctions oder Directory-Symlinks — behoben
- Crash beim Start aus einem gelöschten, gesperrten oder ausgehängten Verzeichnis — behoben
- Crash bei geschlossenem File-Watcher während laufendem Directory-Scan — behoben

**Bugfixes — Agents & MCP:**
- Background Agents blieben nach `SendMessage`-Resume als „failed" oder „completed" gelistet — behoben
- `claude attach` gab Fehler bei Agents im Upgrade-Restart statt zu warten — behoben
- `claude mcp add-from-claude-desktop` hängte bei Servernamen mit ungültigen Zeichen — behoben; ungültige Namen werden jetzt gemeldet, restliche Server werden trotzdem importiert
- Plugin LSP-Server-Fehler verhinderte validen LSP-Server eines anderen Plugins für dieselbe Extension — behoben
- MCP-Servernamen „Claude Browser" wurde reserviert (neben „Claude Preview") — User-konfigurierte Server können diese Namen nicht mehr nutzen

**Bugfixes — PR-Linking & Session:**
- Session-to-PR-Linking übersah PRs, die in Bash-Aufrufen mit >30K Output erstellt wurden — behoben
- Project-Verify-Skills wurden bei jeder Session neu geschrieben statt nur bei Änderungen — behoben

**Bugfixes — UI & Remote:**
- Agent View renderte eine Zeile zu hoch und schnitt den Header ab — behoben
- Background Tasks in Web/Mobile Remote-Control-Panels zeigten veralteten „Running"-Status — behoben

**Verbesserungen:**
- Auto-Update streamt Binaries direkt auf Disk: ~400 MB weniger Peak-Memory
- Agent View: Sessions, die PRs editieren/mergen/kommentieren, verlinken diese in `claude agents`
- Agent View: Rows zeigen jetzt farbigen Status und einen classifier-geschriebenen Headline statt rohen Tool-Call-Text; Peek-View zeigt vollständigen Status inkl. der exakten Frage bei blockierten Sessions
- `/doctor` ist jetzt ein vollständiger Setup-Checkup mit automatischer Diagnose und Reparatur; `/checkup` ist ein Alias
- Cowork VM-Mode Local-Agent-Sessions-Fehler mit „Not logged in" auf CLI 2.1.203+ — behoben

### AWS AI Blog

**[Claude Apps Gateway für AWS](https://aws.amazon.com/blogs/machine-learning/introducing-claude-apps-gateway-for-aws/)**

AWS und Anthropic stellen einen self-hosted Control Plane für Unternehmen vor, der Claude Code und Claude Desktop zentral verwaltet:

- **Identity**: Anbindung an beliebige OIDC-kompatible Identity Provider (SSO). Kurzlebige Token, keine dauerhaften Secrets auf Entwicklermaschinen
- **Policy**: Zentrale Definition von Modell-Zugriff, Tool-Permissions und Settings — erzwungen bei jedem Request
- **Telemetry**: OTLP-basiertes Usage-Tracking nach CloudWatch, Prometheus oder Drittanbieter
- **Routing**: Proxy für Amazon Bedrock oder Claude Platform on AWS mit regionalem Failover
- **Spend Caps**: Tages-, Wochen- und Monatslimits pro Org, Gruppe oder User

Das Gateway läuft als statusloser Container (ECS, EKS oder EC2) mit PostgreSQL-Backend. Konfiguration via einziger YAML-Datei. Modell-IDs entsprechen der Anthropic API (`claude-sonnet-5`, `claude-opus-4-8`).

**[AWS WAF mit AgentCore Runtime](https://aws.amazon.com/blogs/machine-learning/securing-amazon-bedrock-agentcore-runtime-with-aws-waf/)**

Zwei Architekturmuster für WAF-Schutz vor AgentCore Runtime:
- **Pattern 1** (ALB + Lambda-Proxy): Volle Kontrolle über Request-Transformation, +50–200ms Latenz
- **Pattern 2** (ALB direkt zu VPC Endpoint): Einfachste Architektur, keine Lambda-Latenz, kein zusätzlicher Cost

Resource Policy schließt die Direct-Access-Backdoor — ohne Policy können gültige Credentials WAF umgehen.

### 📄 ArXiv Papers

**[Institutional Red-Teaming: Deployment Rules, Not Just Models](http://arxiv.org/abs/2607.07695v1)** ⭐ AI Safety
Neue Evaluierungsmethodik, die Deployment-Regeln (nicht Modelle) als Kausalvariable testet. IABench-CA umfasst 228 Kontexte, 5 kanonische Regeln, 7 Modell-Populationen (33.924 Spiele). Ergebnis: Regeln formen kollektives Verhalten in Multi-Agent-Systemen entscheidend — wichtig für AI Safety Governance.

**[Agon: Competitive Cross-Model RL](http://arxiv.org/abs/2607.07690v1)**
Zwei konkurrierende Modelle bewerten gegenseitig ihre Reasoning-Traces (nicht nur finale Antworten). Verhindert, dass Modelle durch längere statt bessere Antworten trainiert werden.

**[AdaPrefix-GRPO: Adaptive Trace Prefix Control](http://arxiv.org/abs/2607.07674v1)**
Löst das Problem, dass GRPO bei sehr schwierigen Problemen keine Gradienten produziert (alle Rollouts scheitern). Adaptiver Prefix-Controller passt Schwierigkeitsgrad dynamisch an.

**[Selective Timestep Weighting & Advantage-Based Replay für Diffusion RLHF](http://arxiv.org/abs/2607.07693v1)**
Zwei komplementäre Strategien für sample-effizienteres RLHF bei Diffusionsmodellen — adressiert den Feedback-Flaschenhals in realen Szenarien.

**[Co-LMLM: Continuous-Query Limited Memory Language Models](http://arxiv.org/abs/2607.07707v1)**
LMLMs externalisieren Faktenwissen in Knowledge Bases statt es in Weights zu speichern. Co-LMLM verwendet kontinuierliche Keys für KB-Paare — verbessert Knowledge-Control gegenüber klassischen LLMs.

**[Structural Trajectory Analysis für Agent Optimization](http://arxiv.org/abs/2607.07702v1)**
Neue Methode zur Root-Cause-Analyse aus Agent-Execution-Traces: filtert redundante und heterogene Traces, isoliert kausal relevante Fehler für effizientere Optimierung von Long-Horizon-Agents.

**[Jailbreak: Database Lock-in durch Agentic Regeneration aufbrechen](http://arxiv.org/abs/2607.07696v1)**
Umgeht Datenbankengines vollständig durch direktes Lesen von Storage-Dateien — eliminiert JDBC/ODBC-Bottleneck für analytische Workloads.

**[Structure-property Understanding mit Deep Native Structural Reasoning](http://arxiv.org/abs/2607.07708v1)**
KI-Ansatz für mechanistisches Erklären von Struktur-Eigenschafts-Beziehungen in Biologie, Chemie und Materialwissenschaften — kombiniert räumliche Evidenz mit wissenschaftlichen Prinzipien.
