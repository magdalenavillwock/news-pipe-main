#### [Claude Code Releases — v2.1.247](https://github.com/anthropics/claude-code/releases/tag/v2.1.247)

Umfangreichstes Update seit Langem. Alle Features im Detail:

**Neue Features:**
- **`SendFeedback`-Tool**: Claude kann bei Problemen in einer Session automatisch einen Feedback-Report erstellen, den der User reviewen und über `/feedback` absenden kann. Deaktivierbar über Setting `feedbackDrafts`.
- **Anpassbare Spinner-Tips für Organisationen**: `spinnerTipsOverride` unterstützt jetzt `{id, text, cooldownSessions, priority}`-Einträge sowie `tipsFile` und `label` — Organisationen können eigene Tips neben den eingebauten rotieren lassen.
- **Bash-Permission-Prompt-Tip mit Auto-Mode**: Neuer Hinweis beim Bash-Permission-Dialog mit One-Keystroke-Option "Yes, and switch to auto mode".
- **`/claude-api cost-optimize`**: Neuer Skill, der bestehende Projekte auf API-Kosten-Optimierungspotenziale analysiert (Caching, Token Hygiene, Batch, Effort, Model Choice).
- **`/claude-api` Admin API Coverage**: Erweitert um Organization Members, Invites, Workspaces, API Keys, Rate Limit Reports, Workload Identity Federation, CMEK.
- **Sonnet 5 Auto-Compact**: Default Auto-Compact-Window auf volles 1M-Context geändert (Kompaktierung bei ~967K statt ~934K Tokens).
- **Cross-Session Peer Messages**: Nachrichten werden standardmäßig als einzeilige Vorschau `Message from @<sender>: <first line>` angezeigt; Ctrl+O expandiert den vollständigen Inhalt.

**Bugfixes:**
- Behoben: Schnelle Arrow-Key + Enter-Sequenzen lösten Aktionen in der falschen Zeile aus (History Search, `/config`, `/mcp`, `/skills`, Background Tasks, `/model`)
- Behoben: Sub-Agenten starben bei Model-404-Fehler beim ersten Aufruf — nutzen jetzt die Fallback-Model-Chain der Session
- Behoben: Megabyte-große Fehlerausgaben von Hooks/Background-Agenten konnten Session mit "Prompt is too long" blockieren
- Behoben: Ctrl-Shortcuts funktionierten nicht unter nicht-lateinischen Tastatur-Layouts (z.B. Kyrillisch) in Kitty-Protocol-Terminals
- Behoben: Mouse-Report-Escape-Sequenzen (`<35;150;7M`) wurden in Prompt eingefügt
- Behoben: Bash-Sandbox löschte dotfile-managed `~/.claude/settings.json`-Symlink (nix/home-manager, stow) beim Cleanup
- Behoben: `/terminal-setup` überschrieb gesamte Zed `keymap.json` statt nur die Keybinding hinzuzufügen
- Behoben: `/rename` bestätigte schweigend, wenn Session-Registry nicht aktualisiert werden konnte
- Behoben: `/compact` und "Summarize from here" in `--agent`-Sessions nutzte falschen System-Prompt
- Behoben: Background-Session zeigte "opening…" dauerhaft nach dem Tod des Terminal-Host-Prozesses
- Behoben: Unbegrenztes Memory-Wachstum bei nicht-schreibbaren Output-Files von Hooks/Background-Tasks
- Behoben: `/install-github-app` über SSH — Copy-Shortcut behauptete fälschlicherweise immer Erfolg
- Behoben: Shell-Commands aus dem Foreground loggten internen Fehler oder zeigten `[exited with code -1]` in Background-Sessions
- Behoben: Versionsloses Marketplace-Plugin: Live-Cache-Verzeichnis wurde bei Second-Scope-Install gelöscht und neu erstellt
- Behoben: Remote-Control-Sessions via `/remote-control` meldeten Working-Tree-Diff nicht an verbundene Clients
- Behoben: Self-hosted Runner meldete `running` bevor Claude Code gestartet war
- Behoben: First-Run-Setup beendete sich mit "Unable to connect to Anthropic services" bei gateway-konfigurierten Managed Settings
- Behoben: Cloud-Sessions zeigten beim Mode-Switch kurz nach Nachrichtenversand den alten Permission-Mode
- Behoben: Cloud-Sessions wurden "still" nach Container-Restart zwischen Turns mit laufenden Background-Agenten/Shells/Monitoren

**Verbesserungen:**
- Plugin-Marketplace: Namen mit Control/Invisible-Charakteren werden abgelehnt; Marketplace-Text in `/plugin`-Output ist Escape-sicher
- Bedrock/Vertex/Foundry-Sessions: Claude wird jetzt informiert, wenn ein MCP-Server nicht verbunden werden konnte
- Terminal-Hyperlinks: Pfade zu Netzwerk-/Automounter-Paths, mit Control-Zeichen oder unsichtbaren Zeichen werden als Plaintext gerendert
- PR-Badge im Prompt-Footer: Überspringt GitHub-Re-Check bei unter einer Minute altem letzten Check
- Analytics: Bleiben von Startup an aus bei Gateway-Login oder Custom-OAuth-Deployments
- Claude-Apps-Gateway-Signin: Identifiziert Claude Code über `surface=claude_code` und `claude-code/<version>` User-Agent
- Organisation-Signin-Enforcement: Beendet sich beim Start, wenn Administrator-Managed-Settings nicht gelesen werden können

### 📄 ArXiv Papers

**[VBVR-Pro: Scalable Visual Reasoning](http://arxiv.org/abs/2608.26105v1)**: Closed-Loop-Testbed für "Native Visual Reasoning" — visuelle Zustände (Bilder/Videos) als primäres Reasoning-Substrat, nicht nur Input/Output. Skalierbare Trainingsaufgaben mit zuverlässigem Feedback.

**[SwarmWorld: Stigmergic AI Agent Societies](http://arxiv.org/abs/2608.26081v1)**: LLM-Agenten bauen in einer dezentralisierten Umgebung durch Stigmergie (Umwelt-basierte Koordination) funktionale Technologien auf — kollektive Intelligenz ohne vorgegebene Rollen oder zentralisierte Workflows.

**[Prefix Sliding for Test-Time Scaling](http://arxiv.org/abs/2608.26070v1)**: Erkenntnis: Intermediäre Reasoning-Tokens verlieren im Verlauf des Denkens an Bedeutung. Prefix Sliding entfernt diese dynamisch, was lange Reasoning-Ketten deutlich effizienter macht ohne Qualitätsverlust.

**[R³: Robots Reason in Natural Language via RL](http://arxiv.org/abs/2608.26053v1)**: Untersuchung, ob VLMs für robotische Manipulation direkt in Sprache trainiert werden können. Long-Horizon-Tasks erfordern Constraint-Tracking, Fehlerkorrektur und das Steuern von Low-Level-Policies.

**[Sparse Autoencoders on Neutrino Foundation Model](http://arxiv.org/abs/2608.26090v1)**: Erste Anwendung von Mechanistic Interpretability (Sparse Autoencoders) auf ein Teilchenphysik-Foundation-Modell (IceCube-Daten). Validierter Atlas physikalischer Konzepte in der Modell-Repräsentation; kausale Interventionen bestätigen gefundene Features.

**[Planetary Prediction Engine (PPE)](http://arxiv.org/abs/2608.26088v1)**: Autonomes AI-System für End-to-End geospatiale Modellierung: Datenabruf, multimodale Fusion und Modellselektion — für kritische Anwendungen wie Ernährungssicherheit, Katastrophenrisiko und Krankheitsausbrüche.

**[PlanSightRAG](http://arxiv.org/abs/2608.26091v1)**: Visual-First Multimodal RAG für Bauplan-Compliance-Checks. Indexiert direkt über Planzeichnungen (statt OCR), nutzt ColNomic-3B Multi-Vektor-Retrieval und einen Planner-Retriever-Auditor-Synthesizer-Agenten.
