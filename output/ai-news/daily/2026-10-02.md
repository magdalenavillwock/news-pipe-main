### Claude Code Releases

**[v2.1.287](https://github.com/anthropics/claude-code/releases/tag/v2.1.287)**

Dieses Release ist eines der umfangreichsten seit Langem. Hier alle neuen Features und Fixes im Detail:

#### Neue Features

- **Claude Mods**: Plugins können nun tieferes Verhalten von Claude Code modifizieren — ein neues Plugin-Framework für erweiterte Anpassbarkeit
- **"You should know" (Built-in Mod)**: Ein eingebauter Side-Agent, der im Hintergrund mitläuft und Dinge markiert, die Claude oder der Nutzer übersehen könnte. Aktivierung: `/plugin enable cc-plugin-you-should-know@builtin` (nur für First-Party-Sessions mit Telemetrie)
- **Agents-View Filter `n:<text>`**: Filtert Session-Namen und Tasks; zeigt Treffer auch in eingeklappten Bereichen, Enter öffnet den ersten Treffer
- **`prompt_text` in OpenTelemetry**: Neues Feld im `user_prompt`-Event für Backends, die Dotted-Keys verschachteln — soll überall dort maskiert werden, wo `prompt` maskiert wird
- **URL-Prompts von MCP-Servern**: Unterstützung für Sign-In-Prompts via MCP (Protokoll 2025-11-25). Konfiguration: `"bareElicitationCapability": true` in der MCP-Config bei Verbindungsproblemen
- **Windows**: Startup-Warnung wenn das Verweigern des Bash-Tools auch PowerShell deaktiviert
- **Self-hosted Runner**: Eingebautes `gh api` (REST only) für Sessions mit Anthropic-managed Git auf macOS/Linux ohne GitHub CLI
- **[VSCode]** "Run in background" für laufende Befehle oder Sub-Agents
- **[VSCode]** Hintergrund-Shell- und Monitor-Outputs in Agent-Map-Karten

#### Bugfixes (Auswahl)

- Fast Mode blieb in Remote-Sessions mit Agent-Accounts ohne Nutzer-Account aus, auch wenn die Organisation es erlaubt — **gefixt**
- Remote Control verlor Verbindung für Minuten bei fehlenden Reconnect-Responses — **gefixt** (30s Timeout, dann Retry)
- Hooks mit `asyncRewake` und fehlender Script-Datei weckten Claude wiederholt mit "found issues" — **gefixt** (einmalige Fehlermeldung)
- Tool-Heartbeats erreichten SDK-Hosts nicht bei stalled Streams — **gefixt**
- Bedrock/Vertex Startup-Checks ignorierten `availableModels`-Listen — **gefixt**
- Claude in Chrome zeigte JSON-Parse-Fehler wenn Chrome nicht erreichbar war — **gefixt**
- Fable-Modellauswahl speicherte veraltete ID statt der neuesten Version — **gefixt**
- Wechsel zwischen Opus 5.5 und Sonnet 5.5 überschrieb MCP-Tool-Ankündigungen — **gefixt**
- Amazon Bedrock Guardrails-Blocks mitten in Antworten erzeugten API-Fehler statt Guardrail-Nachrichten — **gefixt**
- Gefährliche `rm`-Befehle (z.B. auf `/` oder Home) verloren ihren Always-Ask-Schutz bei bestimmten Output-Redirects — **gefixt** (sicherheitskritisch!)
- `claude -p` und SDK-Sessions wiederholten Model-Fallback bei jedem späteren Message — **gefixt**
- `CLAUDE.md` eines Ordners wurde nach Resume oder Compaction doppelt angehängt — **gefixt**
- Hintergrund-Sessions nach Worktree-Löschung nicht mehr wiederöffenbar — **gefixt**
- `/advisor` Pairing-Checks: Sonnet 5.5 kann nun Opus 4.7 und 4.8 advisen — **gefixt**
- Bash-Permission-Prompts zeigten interne Parser-Namen — **gefixt**
- `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS` entfernte structured-output-Format nicht korrekt für Bedrock-Gateways — **gefixt**
- Viele weitere Screen Reader Mode Fixes (Cursor-Position, Enter auf leeren Feldern, Tab-Hints, Arrow-Keys, Diff-Anzeige, etc.)
- `--include-partial-messages` sendete `message_stop` zu spät — **gefixt**
- MCP-Connector-Tools wurden manchmal doppelt aufgerufen — **gefixt**
- PNG/JPEG/WebP über 8.000 Pixel von Remote-Sessions fehlgeschlagen — **gefixt** (scaled-down copy wird gesendet)
- Nachrichten mit 17-20 Anhängen lieferten nur die ersten 16 — **gefixt**
