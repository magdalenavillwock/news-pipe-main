### Claude Code Releases

#### [v2.1.258](https://github.com/anthropics/claude-code/releases/tag/v2.1.258)

- **Bugfix:** Claude Code startete auf macOS 12 (Monterey) nicht mehr — Regression aus v2.1.255 behoben
- **Bugfix:** Remote- und scheduled Sessions schlugen fehl mit „user messages must have non-empty content" nach einer erneut gesendeten Permission-Genehmigung

#### [v2.1.257](https://github.com/anthropics/claude-code/releases/tag/v2.1.257) — Massives Release

**Neue Features:**
- **Claude Fable 5.1** (`claude-fable-5-1`) als neues Standard-Fable-Modell — 1M Kontext, $10/$50 per Mtok, $0.25/Mtok Cache-Reads
- **Time format & Timezone Settings** (`timeFormat`, `timeZone`): 12h, 24h, UTC oder strftime-Pattern für Turn-End-Uhr und Transcript-Timestamps
- **Containment Escape Rule** im Auto-Modus: Cloud-Metadata-Credential-Fetches, Egress-Evasion und Cross-Tenant-Zugriffe werden nicht mehr automatisch genehmigt (außer explizit markiert)
- **`CLAUDE_CODE_SUBAGENT_MODEL_FORCE`**: Erzwingt das angegebene Modell für alle Subagenten, ignoriert per-spawn Overrides
- **`/effort` + `s`-Flag**: Effort nur für die aktuelle Session ändern (wie `/model`)
- **`/doctor`-Warnung** für veraltete Sandbox-Mask-Dateien nach abgebrochener Session
- **One-Time-Prompt** im Auto-Modus vor dem ersten Datei-Read außerhalb der Working Directories (mit Option zum Blockieren via `permissions.blockReadsOutsideWorkingDirectories`)
- **Gateway-Modellbeschreibungen** für `/model`-Picker-Einträge unterstützt
- **`/add-dir`**: Akzeptiert nun auch Verzeichnisse innerhalb des aktuellen Working Directory
- **VSCode:** Account & Usage / Session Manager Collapsible Headers; Modell-Pill im Input-Footer; Output Style Selection im Command Menu; Slash-Commands in filterbare Dialog verschoben; „Delete session" → „Archive session" mit Unarchive-Aktion

**Wichtigste Bugfixes (Auswahl):**
- Settings in `.claude/`-Ordner der nach Start erstellt wurde wurden erst nach Restart übernommen
- `keybindings.json`-Rebinds von Ctrl+G wurden in `claude agents` ignoriert
- Background Sessions starteten auf macOS npm-Installs bei Self-Updates nicht
- Spinner stoppte während Antwort-Streaming hinter Slash-Command-Panel
- Doppelt gelisteter `Authorization`-Header überschrieb Credentials auf Bedrock, Vertex, Mantle
- Claude apps gateway sendete fremde Host-Header an Foundry, Vertex und Bedrock
- `/schedule`-Routinen mit fehlendem message role liefen ohne Inhalt
- Prompt stashed mit Ctrl+S ging verloren wenn Session idle wurde
- Token-Counter fror ein nach Wechsel zu anderem Subagenten-Transcript
- Sandbox-Netzwerk-Hosts mit Trailing Dot (`.`) wurden in `deniedDomains` nicht blockiert
- Remote Control consent wurde durch Escape als Zustimmung gewertet
- Subagenten stoppten bei abgeschnittenem Stream durch Computer-Sleep oder Server-Error — jetzt automatisches Fortsetzen
- `←` in `/btw`-Panel tat nichts in `claude agents` — jetzt Rückkehr zur Agents-Liste
- Bash `Read()`/`Edit()` deny rules galten nicht für `< file` Redirects und Befehle wie `tac`, `egrep`
- Worktree-Sessions verweigerten Bash-Loops, `$VAR`-Reads, Heredocs unnötigerweise
- Prompt-Cache-Misses bei screenshot-intensiven Sessions nach Überschreiten der Größengrenze
- Sandboxed git commands verloren Write-Access in linked Worktrees nach `cd` in Subdirectory
- Bedrock/Bedrock-Mantle-Requests wurden bei langen Thinking-Phasen still — jetzt Progress Events
- Proactive-Sessions busy-loopten mit Füllnachrichten statt idle zu warten
- Plugins konnten Dateien außerhalb ihres Verzeichnisses per Symlink lesen — jetzt blockiert

**Verbesserungen:**
- Deutlich bessere Rendering-Performance in langen Conversations, Streaming verlangsamt sich nicht mehr mit wachsender Antwort
- `/code-review --comment` postet jetzt auch auf GitLab Merge Requests via `glab mr note`
- `/fork` behält den Prompt-Cache der Original-Conversation im neuen Background-Session
- Emoji-Autocomplete akzeptiert alle GitHub/Slack-Shortcode-Aliases
- Verbesserte Policy-Helper-Diagnostik in `/status`

**Breaking Changes / Änderungen:**
- `defaultMode: "bypassPermissions"` in `.claude/settings.json` oder `.claude/settings.local.json` wird ignoriert
- `/btw`-History-Navigation von `←`/`→` zu `Shift+←`/`Shift+→` (oder `[`/`]`) geändert
- `--add-dir` verweigert Netzwerkpfade (UNC Shares, `/net/<host>` Automounts)
- `fable` und `best` bleiben in Claude-Apps-Gateway-Sessions bei Fable 5 (Fable 5.1 über `/model` wählbar)
- Cowork/claude.ai Cloud Sessions: Artefakt-Reads anderer User fragen jetzt immer nach, auch im Auto-Modus
