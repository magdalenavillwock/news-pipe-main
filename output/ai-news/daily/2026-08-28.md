### Claude Code Releases

#### [v2.1.250](https://github.com/anthropics/claude-code/releases/tag/v2.1.250)

#### [v2.1.248](https://github.com/anthropics/claude-code/releases/tag/v2.1.248) — Das große Release

**Neue Features:**
- **`--restricted` / `CLAUDE_CODE_RESTRICTED=1`**: Entfernt alle Built-in-Tools, die Befehle oder Code ausführen, sowie `WebFetch` (außer explizit via `--tools` angegeben). Hält Datei-Tools innerhalb des Working Directory, verweigert `bypassPermissions` und ignoriert User/Projekt/Local Settings.
- **`experimental.cacheTtl`** im Agent-Frontmatter: Konfigurierbare Prompt-Cache-TTL pro Agent (`"5m"` oder `"1h"`).
- **`claude self-hosted-runner --client-label <label>`**: Überschreibt das Label, mit dem der Runner registriert wird (Standard: Hostname).
- **Server-Managed Settings Diagnostics**: Startup-Warnung bei Ladefehler, `/doctor` und `/status` erklären warum Einstellungen nicht geladen wurden.
- **`/web-setup`-Warnung**: Warnt wenn GitHub CLI Token den `workflow`-Scope fehlt.
- **`/usage-credits`**: Für Enterprise-Organisationen via AWS Marketplace — Mitglieder können höhere Limits beim Admin anfragen.
- **Cross-Session-Messaging** (`SendMessage` / `ListAgents`): Funktioniert jetzt auch auf Bedrock, Vertex und Foundry sowie bei deaktivierter Telemetrie.

**Bugfixes (Auswahl):**
- Prompt-Cache-Miss (und verlorener Extended-Thinking-Kontext) ca. einmal pro Stunde durch Re-Rendering der Tool-Definitionen nach OAuth-Token-Refresh — behoben.
- `ScheduleWakeup`-Tool-Definition-Änderung bei `--resume` wenn Account in Nutzungs-Overage war → vollständiger Cache-Miss — behoben.
- Claude Desktop und Cowork Sessions verschwanden nach 30 Tagen — `desktopSessionCleanupPeriodDays` als neue Einstellung eingeführt.
- Login-Screen-Weiterleitung wenn anderer Prozess den Token-Refresh-Lock hielt — stattdessen retryable Error.
- **Windows**: `claude agents`-Liste reagierte nicht auf Tastatur nach Session-Detach oder in win32-input-mode-Terminals.
- `/login` Console-Sign-in schlug mit OAuth-Fehler fehl auf Maschinen mit gesetztem `ANTHROPIC_API_KEY` — fällt jetzt auf API-Key-Sign-in zurück.
- Modellnamen in `/model` und Fast-Mode-Meldungen rendern jetzt als Code (Suffixe wie `[1m]` zeigen buchstäblich statt als Link).
- `claude agents` übersprang Workspace-Trust-Prompt wenn `CI`-Env-Variable gesetzt war.
- `claude agents` crashte beim Start wenn PR-Status-Cache einen fehlerhaften Eintrag enthielt.
- Agent View resurrected alte Hintergrund-Sessions nach Maschinen-Ausschalten — solche Sessions zeigen jetzt das echte Ende und fragen vor Resume.
- `claude agents` und `claude rm` verweigerten das Löschen von Sessions mit "has commits not pushed" wenn Branch bereits in lokalem main gemerged war.
- Hooks druckten ungültige JSON-Antwort still als Plaintext statt Fehler — jetzt als Hook-Error mit Parse-Meldung gemeldet.
- `/mcp` listete `.mcp.json`-Einträge mit `claude.ai`-Connector-Typ fälschlicherweise unter "claude.ai" — jetzt korrekt unter eigenem Scope.
- MCP-Server mit `headersHelper` für `Authorization`-Header fielen in OAuth-Discovery bei 401 statt Helper neu auszuführen.
- `/ultrareview <PR#>` prüft jetzt vor Launch ob GitHub-Account Repository-Zugang hat.
- `/ultrareview` und Cloud-Sessions luden keine `prod.env`-Dateien, `*.tfvars`, Editor-Swap/-Temp/-Backup-Kopien von Credential-Dateien (z.B. `key.pem.tmp`, `id_rsa.swo`) mehr hoch — bleiben lokal.
- Worktree-Session verlor beim Hintergrundlaufen den Checkout — Background-Session hält jetzt den Worktree-Lock.
- @-Mentions mit nicht-lateinischen Zeichen (z.B. Koreanisch via IME) funktionierten nicht — behoben.

**Verbesserungen:**
- Workflow-Tool: Beschreibung reduziert von 5.7k auf ~1k Tokens (Authoring-Referenz in `workflow-authoring`-Skill ausgelagert).
- PR-Badge im Prompt-Footer fragt GitHub weniger häufig ab solange PR unverändert.
- `/loop`: Self-paced dynamic mode und no-prompt autonomous default jetzt immer verfügbar, auch auf Bedrock/Vertex/Foundry.
- Cross-Session-Messaging: Fallback auf privates `/tmp`-Verzeichnis wenn Standard nicht verfügbar.

**Änderungen:**
- Shift+Enter im Agent View fügt jetzt Zeilenumbruch ein; Ctrl+Enter dispatcht und attacht.
- Anthropic-Telemetrie-Export-Fehler werden jetzt als `[Anthropic telemetry]` auf Debug-Level geloggt statt als `[3P telemetry] OTEL diag error`.
- `SendMessage` von Subagent an andere Session: Ergebnis weist darauf hin, dass Antworten an die Parent-Session geliefert werden.

### 📄 ArXiv Papers

**[WikiSkill: Agent Experience in persistentes Wissen kompilieren](http://arxiv.org/abs/2608.27454v1)**
Framework, das Agent-Skills gemeinsam mit einer persistenten Wissensbasis ko-evolviert. Löst das Problem, dass Erkenntnisse über Skill-Optimierung bisher über Optimierungsverläufe verstreut waren und nicht systematisch wiederverwendet wurden.

**[SWE-Prime: Weniger Trajektorien, bessere Performance](http://arxiv.org/abs/2608.27449v1)**
Statt auf rohe Menge an Agenten-Trajektorien für SFT zu setzen, fokussiert SWE-Prime auf Qualität: Erfolgreiche Trajektorien können trotzdem redundante oder riskante Schritte enthalten. Neue Methoden zur Trajektorienselektion für Software-Engineering-Agenten.

**[MCR-Bench: Echtes Code Review benchmarken](http://arxiv.org/abs/2608.27442v1)**
Kritik an bestehenden Code-Review-Benchmarks: Die meisten vereinfachen Code Review zu einer einmaligen, statischen Entscheidungsaufgabe. MCR-Bench modelliert den iterativen, multi-round Charakter realer Code Reviews.

**[RedEvoAgent: Automatisches Red-Teaming mit erfahrungsgetriebenem Skill-Lernen](http://arxiv.org/abs/2608.27439v1)**
Red-Teaming-Agent für LLM-basierte Agenten in Produktionsumgebungen, wo Jailbreaks schädliche Tool-Nutzung und persistente Statusänderungen auslösen können — gefährlicher als reine Textgenerierung.

**[CritICL: Test-Time Weak-to-Strong Generalization](http://arxiv.org/abs/2608.27455v1)**
Inferenzzeitrahmen, der die strukturierten Fehlermuster kleinerer Modelle nutzt, um größere Modelle zur Laufzeit zu verbessern — ohne wiederholte Generierung oder externe Verifikation.

**[TTPO: Test-Time Policy Optimization](http://arxiv.org/abs/2608.27448v1)**
Neue Methode für Test-Time Training ohne Ground-Truth-Labels. Löst das Instabilitätsproblem von Majority-Vote-Pseudo-Labels durch asymmetrische Fehlerbehandlung.
