### Claude Code Releases

**[v2.1.234](https://github.com/anthropics/claude-code/releases/tag/v2.1.234)** — Release vom 17. August 2026

Eines der umfangreichsten Claude Code Releases. Hier alle Änderungen im Detail:

**Neue Features:**
- **`CLAUDE_CODE_PROJECT_DIR_NAME` Umgebungsvariable** (optional): Hosts, die pro Session eigene Config-Verzeichnisse vergeben, können damit einen kurzen Namen für das projektspezifische Transcript-Verzeichnis definieren.
- **`selection:clear` Keybinding-Action**: Ein Tastenkürzel kann jetzt belegt werden, um die aktuelle Textauswahl in der App zu löschen — funktioniert auch in der Agents-Ansicht.
- **GitLab Merge Request Badge**: Repos mit GitLab-Remote und authentifiziertem `glab` CLI zeigen jetzt `MR !N` mit Draft/Pending/Grün-Status in Footer und Statusleiste.
- **Automatische Session-Fortsetzung bei Usage-Limit-Reset**: Claude Code nimmt die Session automatisch wieder auf, sobald ein claude.ai Usage-Limit zurückgesetzt wird. Kann in `/config` deaktiviert werden ("Continue automatically at usage limit").
- **E-Mail-Nutzungsbeschränkung**: Claude wird angewiesen, die Account-E-Mail nur zur Identifizierung zu nutzen, nicht um sie an fremde Services zu senden.
- **`/permissions` während laufender Session öffnbar**: Regeländerungen greifen noch im aktuellen Turn.
- **`/add-dir <path>` während aktiver Session**: Verzeichnisse können jetzt auch während Claude arbeitet hinzugefügt werden.
- **Verbesserte Session-Titel**: Automatisch generierte Titel sind jetzt kurz und präzise (z. B. „Login button bug" statt „Fix the login button on mobile").
- **`/goal`-Verbesserungen**: Löscht sich selbst bei nicht behebbaren Fehlern (z. B. widerrufener Auth); nach 30+ Minuten mit wartenden Background-Tasks checkt Claude aktiv ein.
- **`SendMessage` und `ListAgents`** melden jetzt, wenn die Account-Session-Liste zu lang für eine vollständige Prüfung war.
- **Background-Task-Notifications** werden jetzt als `<system-reminder>`-Tags an das Modell übergeben.
- **Transkript-Verbesserung**: Eigene Prompts werden jetzt mit Markdown gerendert (Code-Highlighting, Listen etc.).
- **Verbesserter API-Fehler**: Zeigt jetzt Content-Type, Body-Typ, Größe, Request-ID und Grund des ursprünglichen Streaming-Fehlers.
- **Reduzierte Context-Kosten** für den eingebauten `claude-api`-Skill: Von ~200k+ auf ~25k Tokens durch On-Demand-Laden der Referenzdocs.
- **Remote Control**: Kontoänderungen stoppen laufende Sessions innerhalb von Sekunden mit Erklärung. Effort-Einstellungen von Telefon/claude.ai/code werden übernommen.

**Security-Fixes:**
- **Windows NT-Namespace-Pfade (`\\??\`)** werden jetzt bei Remote-File-Reads, Session-Restore, CLAUDE.md-Includes, Workflow-Scripts und File-Uploads abgelehnt — Härtung gegen NTLM-Credential-Leak-Vektoren.
- **Credential-Masking auf Permission-Previews** kann keine Befehle, Pfade oder Ziele mehr vor dem Genehmiger verbergen. Zu große Private-Key-Blöcke werden vollständig geschwärzt.
- **Provider-API-Tokens** werden maskiert, auch direkt gefolgt von Shell-Delimitern.
- **`strictKnownMarketplaces`-Fix**: Allowlists akzeptierten SCP-style Git-Marketplace-Sources nicht mehr, wenn der Host vom tatsächlich verbundenen Host abweicht.

**Bugfixes (Auswahl):**
- Auto-Mode in langen Sessions prüfte Sandbox-Netzwerkzugriff nach Compaction nicht mehr wiederholt falsch.
- Session-scoped Permission-Antworten (inkl. Denials) wurden nicht mehr bei Background-Subagent-Prompts verworfen.
- Crash behoben bei API-Antworten ohne `thinking`- oder `text`-Feld auf Non-Streaming-Fallback-Pfad.
- Extrem langsames Markdown-Rendering bei ungewöhnlichen Unicode-Sequenzen behoben.
- `SendMessage`-Fehler bei Empfängernamen am 200-Zeichen-Limit oder mit Emojis behoben.
- Repository-Detection las Host von Git-Remotes mit ungewöhnlichem Userinfo falsch.
- MCP-Diagnostics druckten keine aufgelösten Secrets mehr in Scope-Conflict-Warnungen.
- Modal-Text (z. B. `/login` OAuth-URL) verlor Zeichen beim Kopieren im Fullscreen-Modus.
- `---` Horizontal Rule in Markdown lief in die nächste Zeile.
- Aufeinanderfolgende Shell-Befehle wurden in mehrere „Ran 1 shell command"-Zeilen aufgeteilt wenn Todo/Task-Updates dazwischen kamen.
- Dialoge wie `/permissions` wurden geschlossen, wenn ein `!`-Shell-Befehl fertig wurde.
- Queued `!`-Shell-Befehle wurden nach Up-Arrow-Edit als Klartext ans Modell gesendet.
- Queued Messages tauchten in der Prompt-History auf, während sie noch in der Queue waren.
- Fullscreen-Renderer-Prompt setzte die Session ohne Permission-Mode neu.
- `/tui` verwarf `--allowed-tools`/`--disallowed-tools` beim Neustart.
- Trust-Prompts warnte nicht vor Repository-weitem Scope, wenn das Verzeichnis vor dem Repo existierte.
- IDE-Diff-Tab-Schließen während Re-Prompt beantwortete den neuen Prompt mit altem Input.
- Remote Control: Dateien, die während Sessionen an den User gesendet wurden, wurden jetzt korrekt hochgeladen.
- Nach `/login` mit gesetztem `CLAUDE_CODE_OAUTH_TOKEN` leckte das Stale-Token-Reminder in Claudes automatisch fortgesetzte Antwort.
- Claude Desktop Inter-Session-Messages wurden stillschweigend verworfen.
- Windows: Startup stotterte bei `~/.claude.json` mit Read-Only-Rechten.

**Sonstige Änderungen:**
- Esc im Fullscreen-Modus löscht jetzt keine Maus-Textauswahl mehr.
- „Allowed by auto mode classifier"-Zeile unter Agent-Tool-Calls entfernt.
- „Default teammate model"-Einstellung aus `/config` entfernt.
- Elapsed-Time-Counter in laufenden Tool-Headern gedimmt.

### Claude Agent SDK

**[v0.3.234 (TypeScript)](https://github.com/anthropics/claude-agent-sdk-typescript/releases/tag/v0.3.234)**

**Breaking Changes:**
- **`bypass_permissions_disabled` aus `ExitReason`-Typ entfernt**: Der Wert wurde nie emittiert. TypeScript-Consumer mit explizitem `case`-Branch erhalten beim Upgrade einen Compile-Error (Runtime unberührt).

**Updates:**
- **`ApiKeySource`-Typ aktualisiert**: Enthält jetzt die tatsächlich gemeldeten Werte: `ANTHROPIC_API_KEY`, `apiKeyHelper`, `/login managed key`, `none`.
- **`vcs_state_changed`-Events**: Berichten jetzt das Verzeichnis, in dem die Shell endete (ein internes `cd` wird reflektiert).
- **Peer-`origin`-Injection**: Ein vom Host injizierter Peer-`origin` kann jetzt die Permission-Klasse der sendenden Session (`fromMode`) deklarieren, sodass gleichklassige Messages ohne Nachfrage zugestellt werden.
- **`SDKSystemMessage` (`system`/`init`)**: Neues optionales `effort`-Feld — das angewendete Effort-Level der Session oder `null`. Wird bei Remote Control Bridge Init Frames gesetzt.

**Update-Befehl:**
```sh
npm install @anthropic-ai/claude-agent-sdk@0.3.234
```

MIT/Harvard-Forscher entdeckten „Role Drift" in zusammengesetzten KI-Systemen: Beim End-to-End-RL-Training lernt ein RAG-Reader, Fragen aus seinem internen Gedächtnis zu beantworten statt aus abgerufenen Dokumenten — obwohl die Gesamt-Accuracy steigt. Die Lösung „Role Anchor" hält Module bei ihrer zugewiesenen Rolle durch einen Regularisierungsterm — ohne Latenz-Overhead beim Inference.

## 📄 ArXiv Papers

**[BATON: Long-Horizon Robot Manipulation via Agentic Subtask Exploration](http://arxiv.org/abs/2608.16889v1)**
Lösung für das Problem, dass VLA-Modelle einzelne Robotik-Skills beherrschen, aber Ketten davon scheitern. Ansatz: LLM übernimmt Planung in Sprache, analytische Primitiven für Freiraum-Bewegung, VLA nur für kontaktreiche Segmente.

**[Matrix Multiplication Exponent ω mit AlphaEvolve verbessert](http://arxiv.org/abs/2608.16884v1)**
Nutzt moderne ML-Optimierungsverfahren und AlphaEvolve, um das Kombinationsverlust-Analyse-Optimierungsproblem in größerem Rahmen zu lösen und die theoretischen Schranken für ω zu verbessern.

**[AutoSR: Automatische Symbolische Regression](http://arxiv.org/abs/2608.16876v1)**
Vollautomatisiertes System, das persistente wissenschaftliche Untersuchungen statt isolierter Gleichungen durchsucht — adressiert das Problem numerisch guter aber wissenschaftlich unplausibler Ausdrücke.

**[Computational Provenance: Kausale Evidenz in generiertem Text](http://arxiv.org/abs/2608.16868v1)** *(cs.AI + cs.CL)*
Untersucht, ob generierter Text nachweisbare Evidenz über den internen Berechnungszustand tragen kann — relevant für Interpretierbarkeit und Audit-Fähigkeit von Sprachmodellen.

**[Was lesen Compliance-Detektoren? Audit von Activation Probes und Guard Models](http://arxiv.org/abs/2608.16852v1)**
Zeigt „Regelblindheit" bei aktuellen Compliance-Detektoren: Das Löschen der eigentlichen Regel aus dem Prompt verändert das Urteil kaum. Kritisch für Regulated-AI-Deployments.

**[Proteus: Incremental Memory Activation für Long-Context-Modellierung](http://arxiv.org/abs/2608.16844v1)**
Adressiert das Problem, dass statische Memory-Modelle frühzeitig Kapazität „verschwenden" — Proteus aktiviert Memory inkrementell und verbessert damit die Effizienz für lange Sequenzen.

**[Model Hypnosis: Starke KI-Kontrolle via sublimale Effekte](http://arxiv.org/abs/2608.16834v1)**
Zeigt, dass individuell schwache, irrelevant wirkende Prompt-Cues (Paraphrasen, Tippfehler) systematisch kombiniert werden können, um das Modellverhalten stark zu steuern — auch bei Frontier Reasoning Models. Hypnotische Prompts transferieren zwischen Modellen. Erhebliche Sicherheitsrelevanz.

**[Policy Iteration with Human Feedback (PIHF)](http://arxiv.org/abs/2608.16831v1)**
Überträgt die RL-Struktur von Evaluate-and-Improve auf In-Context Learning: Revision findet in versionierter natürlicher Sprache statt, kein Gradient-Update nötig.

**[ClawGym II: Black-Box RL auf Agent Harnesses](http://arxiv.org/abs/2608.16798v1)**
Präsentiert ein einheitliches Black-Box-RL-Framework für stabile und skalierbare Optimierung von allgemeinen Agents durch komplexe Harnesses — löst Herausforderungen beim RL-Training für Long-Horizon-Tasks.
