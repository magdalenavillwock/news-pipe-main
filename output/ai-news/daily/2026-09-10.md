### Claude Code Releases

**[v2.1.267](https://github.com/anthropics/claude-code/releases/tag/v2.1.267)** — 9. September 2026

Eines der umfangreichsten Releases seit langer Zeit. Highlights:

**Neue Features:**
- **`maxEffortLevel`-Setting**: Neues Top-Level- oder per-Modell-Setting unter `modelSettings`. Begrenzt das maximale Effort-Level bei allen Providern (inkl. Bedrock, Vertex, Foundry). User können noch ein niedrigeres Level wählen, aber nie höher als der Cap.
- **`--system-prompt-snapshot off`**: Rendert den System-Prompt bei jeder Anfrage neu, statt den aufgezeichneten Prompt der Konversation wiederzuverwenden — nützlich beim iterativen Entwickeln von Prompts.
- **Claude Tag**: Neuer "Use a custom connector"-Link in den Admin-Einstellungen, um ohne Neustart auf benutzerdefinierte Verbindungen zu wechseln.

**Bugfixes (Auswahl):**

*Cloud & Sessions:*
- Cowork-Scheduled-Tasks in der Cloud schlugen beim Start für Organisationen mit Sandbox-Anforderungen fehl → behoben.
- Abgelaufene AWS/GCP-Credentials unter Host-Apps (z.B. Claude Desktop) zeigten erst nach 10 Retries den richtigen Re-Authentifizierungsfehler → behoben.
- Resume nach `/compact` oder Slash-Command: kein spurioser "Continue from where you left off."-Turn mehr.
- Große Sessions (Transcript >5 MB): Parallele Tool-Calls und Hook-Outputs wurden beim Reload nicht mehr verworfen.

*Prompt-Cache-Fixes (sehr umfangreich):*
- Subagenten und Sessions mit `--system-prompt`/`--append-system-prompt` zeichnen System-Prompt und Tool-Definitionen jetzt einmalig auf statt sie jedes Mal neu zu rendern.
- `/model`-Wechsel triggerte unnötige Prompt-Cache-Misses → behoben.
- Resumed Sessions überschrieben keine MCP-Tool-Ankündigungen mehr vor Reconnect der Connectors.
- Print-Mode (`-p`) → interaktive Resume: System-Prompt-Prefix ändert sich nicht mehr.
- Hintergrund-Worker: `EnterWorktree` wurde nicht mehr mitte in den Tool-Block der Konversation eingefügt.

*UI/UX:*
- `/context` und andere lokale Commands renderten auf mobilen Clients blank → behoben.
- Shift+Enter und Option+Backspace funktionierten nach Reconnect zu tmux/SSH nicht → behoben.
- `/diff`-Panel: Kein kurzes "0 files changed"-Flackern mehr.
- Dim Last-Prompt-Header im Fullscreen-Modus bei Scroll nach oben fehlte → behoben.
- Prompt-Input-Responsivität: Tastendrücke verzögerten sich nicht mehr hinter Spinner-Repaints.
- Verbesserte Bash-Tool-Beschreibung: Claude beschreibt jetzt, was ein Befehl tut, statt ihn einfach zu wiederholen.

*Sicherheit:*
- Marketplace-Pfad mit Backslash konnte den Containment-Check auf macOS/Linux umgehen → behoben.
- `allowedHttpHookUrls`, `httpHookAllowedEnvVars`, `allowedChannelPlugins`: Zeigten bei unlesbaren Managed Settings alles an statt nichts → behoben.

*Workflow:*
- `agent()`-Calls mit großen Output-Schemas wurden im Auto-Mode abgelehnt statt vom Safety-Classifier geprüft → behoben.
- `effort:`-Frontmatter in Custom Commands/Skills/Subagents wurde auf Modellen ignoriert, deren Default-Effort noch gepinnt ist (Opus 4.7, 4.8, Fable 5) → behoben.

*Weitere:*
- Claude Tag: Falscher "API rejected as invalid"-Fehler bei aufgebrauchten Credits → nun korrekte Fehlermeldung.
- Claude Tag: Thread-Requests zum Bearbeiten von Claude-Posts wurden falsch beantwortet → behoben.
- Gateway: `forward_user_identity`-Upstreams geben 429 direkt weiter statt auf nächsten Upstream zu failovern.
- Artifact-Publishes nach Verbindungsunterbrechung: Einmaliger Retry wenn Upload nie abgeschlossen → behoben.
- Remote Control: Stale Permission Mode bis zur nächsten Änderung angezeigt → behoben.
- `claude remote-control`: Server-Credential-Ablauf nach ~30 Tagen ließ alle Sessions fallen → jetzt Re-Registrierung.
- Usage-Limit-Warnung flackerte bei Modell-/Mode-Mix → behoben.

*VSCode-spezifisch:*
- Extension Host hing bei 100% CPU bei Fork/Edit/Rewind bei Transcript mit zyklischem Parent-Link → behoben.
- Screenshot-Paste auf WSL2/WSLg fügte rohe Bild-Bytes ein → behoben.
- Chat-Diff-Blöcke ignorierten das aktive VS Code Color Theme → behoben.
- RTL/Englisch-Text-Rendering-Reihenfolge beim Tippen → behoben.
- Diff-View-Akzeptanz bei Windows (CRLF) Line Endings schlug fehl → behoben.
- `@`-Mentions droppten Dateipfade mit Leerzeichen → behoben.
- Sessions-Liste in Remote-SSH-Windows schlug fehl → behoben.
- Runaway Ripgrep-Prozesse bei großen/symlink-reichen Workspaces → behoben.

*Claude Code on the web:*
- GitHub Enterprise Server Sessions zeigten Konto als disconnected nach Token-Ablauf → automatisches Refresh.
- `gh`/GitHub API schlug in Organisationen ohne Claude GitHub App fehl → Fallback auf verbundenes GitHub-Konto.

## 📄 ArXiv Papers

**[Show-Harness: Just a VLM Agent Can Play Robots](http://arxiv.org/abs/2609.10522v1)**
Präsentiert ein "Embodied Harness", das VLMs über ein kompaktes semantisches Interface mit Robotern verbindet. Diskrete semantische Aktionseinheiten werden deterministisch in Roboter-Aktionen übersetzt — ohne modellspezifisches Finetuning.
