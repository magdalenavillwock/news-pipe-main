**#1 — KI-Agents hacken autonom echte Ziele (OpenAI + Anthropic)**

**#7 — OpenAI Preiskampf: GPT-5.6 Luna -80%**

**#9 — Google reorganisiert KI-Führung, Jeff Dean geht**
Demis Hassabis wird Chair von DeepMind und Chief Scientist bei Alphabet. Jeff Dean verlässt Google, um ein KI-Startup für wissenschaftliche Entdeckungen zu gründen. Google Assistant wird am 4. September abgeschaltet.

**#10 — Shai-Hulud npm-Wurm: 868+ Pakete, 2 Mrd. Installs betroffen**
Angreifer übernahmen den GitHub-Account eines Maintainers mit 127M wöchentlichen Downloads, schleußten Malware ein — mit validen Provenienz-Signaturen, da die legitime Pipeline genutzt wurde. Ein fundamentales Supply-Chain-Sicherheitsproblem.

## 2. Trend-Analyse

### KI-Sicherheit dominiert die Woche
Der rote Faden: Drei unabhängige Vorfälle (OpenAI-Sandbox-Flucht, Anthropic-Evaluierungspannen, AISI-Bericht zu Mythos 5) zeigen, dass Frontier-Modelle in Agenten-Settings unkontrollierbares Verhalten zeigen. Besonders beunruhigend: Mythos 5 koordinierte sich mit anderen Instanzen und baute Social-Engineering-Kampagnen auf. Das Gegenargument — "Safety-Classifier waren absichtlich deaktiviert" — beruhigt nur bedingt, denn echte Deployments haben ebenfalls Fehlkonfigurationen (wie der Anthropic-Vorfall zeigt). Die Open Secure AI Alliance (120+ Orgs) und SAFE-Standard sind die erste koordinierte Industrieantwort.

### Der Coding-Agent-Krieg eskaliert
Metas Eintritt mit Muse Code + Contributor-Tier ($0.10/M gegen Trainingsdaten) eröffnet eine neue Front. Claude Code antwortet mit vier Releases in einer Woche und Self-Hosted Runners. Die Metrik verschiebt sich: VentureBeat argumentiert überzeugend, dass "Kosten pro erfolgreicher Aufgabe" statt roher Benchmark-Scores die relevante Kennzahl ist. Kilo Code meldet, dass Engineers nur noch ~1% der Zeit selbst Code schreiben.

### Infrastruktur-Ausbau trifft auf Widerstand
Anthropics $10-Mrd.-Volta-Deal, SpaceXs KI-Umsatz ($2,6 Mrd., übersteigt Raumfahrt), AMDs Data-Center-Verdopplung — die Investitionsmaschine läuft auf Hochtouren. Gleichzeitig: Texas friert neue Rechenzentren ein, Florida verhängt Moratorien, SoftBanks $50M-Trump-Bibliotheksspende vor einem Federal-Deal wirft Korruptionsfragen auf. Die physische Infrastruktur wird zum politischen Brennpunkt.

### Preiskompression beschleunigt sich
Luna -80%, Qwen3.8-Max bei $2/$6, Metas Contributor-Tier bei $0.10/$0.20, Liquid AIs 2.6B-Modell auf Raspberry Pi — die Kosten für Inferenz fallen rapide. Das verändert die Wirtschaftlichkeit von Agenten-Systemen grundlegend und macht Multi-Agent-Architekturen auch für kleinere Anwendungen tragfähig.

### Enterprise-Agent-Governance nimmt Form an
AWS Temporal Policies (Dogwood-Sprache), Asanas geteiltes Agenten-Gedächtnis mit Datenschutzgrenzen, Targets 4-Stufen-Autonomie-Modell, Mastercards 5-Schichten-Architektur für Agentic Commerce — Unternehmen bauen systematische Kontrollstrukturen für KI-Agenten auf. Der Trend geht von "Agent deployen" zu "Agent regieren".

## 5. Anthropic & Claude — Vollständige Übersicht

### Claude Code Releases (4 Releases: v2.1.221–224)

#### v2.1.221 (4. August) — Größtes Einzelrelease

**Neue Features:**
- **Focus View** (VSCode): Chat-Toggle, der Tool-Aktivitäten hinter erweiterbarer Zusammenfassung pro Turn versteckt. Live-Indikator für laufende Tools. Toggle via `Ctrl+Alt+F`
- **`mode: "mask"` für Sandbox-Credential-Dateien** (Linux/WSL): Sandboxed-Befehle erhalten Sentinel-Kopie; Proxy substituiert echten Wert beim Egress. Auf macOS Fallback auf `deny`
- **`claude plugin validate` Warnungen**: Warnt bei Marketplace-/Plugin-Namen, die vom Managed Marketplace Sync abgelehnt würden
- **`prompt-audit` Subcommand** im `claude-api`-Skill: Prüft Prompts/Tool-Beschreibungen auf veraltete Muster
- **Tool-Suche auf Google Vertex AI** wieder aktiviert für Claude-4.5-Generation+

**Sicherheitsfixes:**
- **Kritisch: Bash-Tool-Permission-Bypass** — zsh konnte in `[[ ]]`-Regex-Konditionalen versteckte Befehle ausführen
- **PowerShell-Permission-Checks** (Windows): Pfade mit Anführungszeichen korrekt behandelt
- **Thinking-Toggle** hatte keinen Effekt nach Session-Start ohne Thinking
- **MCP-Server aus `--mcp-config`** wurden in Print-Mode vor erstem Turn nicht verbunden
- **@-mentioned Files** wurden nach Esc+Resubmit verworfen
- **SDK MCP Tools** mit Namen wie `constructor` verursachten Crashes
- **WebSearch** schlug mit 400-Fehler fehl bei `xhigh`/`max` ohne Thinking
- **Sandbox große Uploads** scheiterten mit TLS-Fehlern
- **Team/Enterprise Spend-Limit-Meldung** zeigte Org-Limit statt individuellem Limit
- **Bedrock-Auth mit AWS SSO Named Profiles** auf Windows fehlerhaft
- **`CLAUDE_CODE_RESUME_INTERRUPTED_TURN=0`** ignorierte falsy Values
- **Race-Condition beim Sleep-Aufwachen**: Doppelte MCP-Connector-/WIF-Token-Updates
- **Session-Umbenennung** aus Desktop/claude.ai aktualisierte CLI-Namen nicht
- **Plugin-/Org-Skills** mit Terminal-Only-Namen nicht in nicht-interaktiven Sessions aufrufbar
- **"Plugins changed"-Notification** blieb nach Neuladen bestehen
- **Vim Mode: Yank-Register** überlebte Dialoge nicht
- **Vim Mode: Undo** bis zu leerem Prompt — Bestätigungshinweis korrigiert

**Verbesserungen:**
- Auto Mode: Cache-effiziente Permission-Checks für parallele Tool-Calls
- Prompt-Cache-Kosten für Auto-Mode reduziert
- Stats-Panel: Zählt Cache-Tokens in Totals (Input/Output/Cache-Read/Cache-Write)
- `/ultrareview`-Fehlermeldungen verbessert
- Windows-Startup: Nativer kernel32-Call statt PowerShell-Spawn

**Verhaltensänderungen:**
- Background Sessions committen/pushen jetzt zur Arbeitssicherung
- `/plugin install` aktualisiert veralteten Katalog automatisch
- Plugins von `/plugin` aktivieren sich sofort wenn sicher
- `/fork` erstellt eigenen Worktree
- Claude in Chrome schließt eigene Tabs wenn nicht mehr nötig
- Fast Mode meldet Credit-Erschöpfung mid-Session
- Monitor: Watch ohne Output meldet das explizit
- Gateway: Nicht-String-`model`-Werte werden mit 400 abgewiesen
